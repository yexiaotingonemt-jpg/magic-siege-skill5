# 0.5.0 发布候选

客户端/服务器0.5.0，战斗兼容0.5.0，协议2。内容与数值见[完整规则](../rules/15-traits-and-elites.md)。

已实施：升级选择与90类词条、五职业技能重配、领主无天赋、持续腐蚀、基础单体连轰、星形非递归治疗、精英波与随机Buff、全员广播与战报、选卡及已选构筑界面。

验证：446项Node逻辑测试、22项完整浏览器回归、5项源码Electron回归及5项最终打包EXE回归全部通过。修正后配套客户端和服务端另通过9项包级验收，包括两台EXE的精英广播、金色选卡及跨职业保留选卡；31份服务端/共享文件和5份预构建页面文件逐一核对一致。

另已新建任务“魔法王座 v0.5.0：独立测试与质量验收”，完成[独立验收报告](0.5.0-independent-acceptance.md)。交接旧包发现的护卫生命上限、烙印爆炸文案、跨职业选卡及治疗反击缓存4项P2均已处理，源码修正由该任务独立复测通过。该报告保留旧包不推荐发布的历史结论；最终重打包及配套验证由主开发任务完成，见[最终包验收](0.5.0-final-candidate-acceptance.md)。

公开版本接口已读取到线上0.4.6（兼容0.3.3、协议1）；本轮0.5.0尚未切换。当前fork未包含服务器连接说明和客户端签名私钥；待补充仓库外的凭据路径后，先核对线上0.4.6相对Git基线0.4.5的变化，再按先上传签名客户端、再备份账号和切换服务端的顺序发布，不覆盖既有正式包。正式账号库不进入Git或发布包。


界面证据：[桌面选卡](../assets/v0.5.0/desktop-draft.png)、[手机选卡](../assets/v0.5.0/mobile-draft.png)、[最终EXE金色选卡](../assets/v0.5.0/final-exe-gold.png)、[最终EXE精英战报](../assets/v0.5.0/final-exe-elite-report.png)。36组初步仿真见[数值报告](0.5.0-balance.json)，独立816组的基线原始结果见[阵容报告](0.5.0-independent-compositions.json)。这些是固定场景与脚本操作的校准数据，不是玩家胜率。技能时机可翻转胜负；初始100体力样本止于15—17级，未保证单次体力体验全部四金。正式平衡仍需带兵线、塔援的真人长局验证。
