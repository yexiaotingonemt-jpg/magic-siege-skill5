# 超级账号权限与性能诊断调整

## 权限维护

超级账号权限继续由正式服数据目录的 `super-accounts.json` 按已有账号内部 ID 授予，不按名称或房主身份自动提升。维护前备份账号库及名单，保留已有授权，再原子替换名单；账号数据和备份不提交 Git，也不随发布包分发。

2026-10-31 已为本次指定的已有账号追加授权，使用当前发布目录的 `Accounts.get` 和 `Accounts.public` 验证超级标记为 `true`。操作未重启服务，客户端重新登录后显示超级账号工具。本机运维凭据和备份位置遵守[服务器连接说明](../服务器连接与密钥.md)。

## 性能诊断

性能诊断沿用独立的访问条件：账号名称必须精确为 `yxt`，且服务端返回 `isSuperAdmin: true`。其他超级账号可使用房主工具和“重开本局”，不因此取得性能诊断权限。

- 有权限时采样帧率、长帧、各绘制阶段耗时、单位和光效负载、快照间隔及处理耗时。隐藏窗口、失焦和切换战局后重新计时，最多保留约 10 分钟记录，可手动导出 JSON。
- 桌面主进程使用当前会话向 `/api/me` 核验权限，不信任渲染进程传入的账号或超级标记。日志写入应用用户数据目录 `performance-logs/performance.jsonl`，串行写入、单条上限 64 KiB、轮转最多两个 5 MiB 文件。
- 普通账号及其他超级账号不显示入口、不创建采样器；切换账号后重新判断权限。日志不包含密码、会话 Cookie 或账号库。
- FPS 分组只展示负载相关性；绘制阶段耗时不包含 GPU 执行时间，不直接作为性能瓶颈的因果结论。

## 提交与发布范围

本次提交包含性能诊断源码、权限校验及配套测试。正式服本次仅更新独立权限名单，服务版本仍为 `0.6.1`。性能诊断代码尚未作为新版客户端发布；正式发布仍需遵守[两端统一版本约定](../版本发布约定.md)。

验证覆盖按 ID 动态授予和撤销、非房主超级账号、全局重开请求权限与幂等、性能日志轮转、浏览器诊断可见性、普通账号伪造 IPC 拒绝，以及桌面实际日志写入。
