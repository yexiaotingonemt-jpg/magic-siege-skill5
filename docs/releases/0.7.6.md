# 0.7.6 体力经验与整数升级曲线

客户端与服务器统一发布为0.7.6；战斗兼容0.7.0，协议3，战局schema3、账号schema1。

每点实际消耗体力获得100经验，契约和施法共用扣费入口。成功契约消耗3点体力、获得300经验；失败、补充体力、击杀和推塔不提供经验。

职业从0级开始，升至1～7级每级5点体力，8～14级6点，15～20级7点，21～26级8点，27～33级9点，34～40级10点。升满合计300点体力、30000经验。每次升级获得1次词条三选一机会，未选可积攒，40级共40次，升级余量保留。

保留战局热更按原/新经验倍率换算现存经验余量，已有等级、构筑、待选、体力、积分和冷却保持；换算有回滚且同倍率更新不重复换算。全部新玩家与后续成长采用新曲线。

客户端继续手动拉取完整仓库后运行根目录魔法王座.exe。旧版由服务端拦截。
