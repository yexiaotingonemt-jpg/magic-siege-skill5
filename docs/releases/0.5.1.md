## 本次改动

- 服务端增量热更与本机私有控制通道；默认保留战局，可明确选择重开。
- 服务端必须先推送 GitHub 发布分支，再从不可变提交生成包；激活前独立验证仓库、分支、文件内容及新提交包含线上提交的关系。
- 更新失败恢复旧运行状态与 current 指向；保留模式维持真实对象、技能队列、登录会话及 SSE。
- 打包可使用 MAGIC_ELECTRON_CACHE 指定已通过官方校验的 Electron 缓存，避免重复下载运行环境。
