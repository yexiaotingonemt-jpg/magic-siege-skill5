# 0.7.20 技能目标与射程调整

客户端与服务器统一发布号0.7.20；战斗兼容0.7.0、协议3、战局schema3、账号schema1保持。

- 腐蚀炮弹取消攻击力200%的伤害封顶，直接按主目标最大生命比例计算总池，保留最多6人及多人衰减和分担。伤害强化移除攻击上限增量。
- 黑暗领主裂地震荡基础最多5人，新增紫色目标增加词条，两档额外命中1／2人，最终最多6／7人；原金色减疗词条保留。

同步技能说明、职业规则、配置契约及实际引擎回归。原始钉钉快照保留，新增词条使用独立ID，已有强化不重分配。构建配套仓库预构建客户端，玩家需退出旧客户端后拉取完整main，再运行根目录魔法王座.exe。

采用保留战局增量更新；发布前对真实线上配置预演保留与回滚，确认账号、战局、玩家、单位、资源、冷却和待执行技能引用保留，引导层未改动。实际正式服激活及客户端验收以配套部署记录为准。
