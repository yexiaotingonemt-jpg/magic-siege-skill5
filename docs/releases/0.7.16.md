# 0.7.16 更新说明

- 黑暗领主裂地震荡命中原前方范围内所有敌人，取消人数上限；原金色“目标增加”词条替换为“减少治疗效果”：受到治疗降低50%，持续3秒。
- 尖刺外壳基础持续5秒，反弹普通攻击和技能攻击；反伤按攻击者来袭时的攻击力计算，不递归反伤。
- 灭军君临基础持续5秒，期间免疫任何伤害及负面效果，保留普攻附带范围伤害。与尖刺同时开启时仍可反伤。
- 同步技能详情、状态提示与[黑暗领主规则](../rules/classes/dark-lord.md)。客户端与服务端统一为0.7.16，战斗兼容0.7.0、协议3保持不变。

本次按用户要求采用保留战局热更：保留当前玩家、英雄、成长、积分、体力、冷却及已排队技能；现有技能按释放时快照继续结算，后续施法采用新配置。已持有原金色目标词条的档位保留，后续震荡施法改为减疗效果。房主已有配置覆盖继续保留。

本次为已确认技能设计的功能发布，当前设计仍标记“待平衡”。旧规则积分校准入口的标准门禁通过，但不覆盖本次新技能；既有40秒大招、小数前摇与策略收益未达项保留，不以功能回归宣称整体平衡通过。
