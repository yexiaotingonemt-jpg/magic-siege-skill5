# 0.7.31 精英积分BUFF

本次客户端与服务端统一发布为0.7.31，战斗兼容0.7.0、协议3。包含此前0.7.30的精灵治疗计分系数0.15及旧积分衔接。

- 精英在开局600秒后首次出现，此后每600秒双方各1名；刷新独立于普通兵线，战区重建不重置开局时间轴。
- 任意有效英雄击杀精英，获得60秒「积分 +50%」；不叠加，再次击杀刷新首棒。
- 击杀敌方持有者后，按60/45/30/15秒重新计时，第五位固定领取200积分并结束传递；末棒奖励不享受增幅。
- 战斗单位只记录最后造成有效伤害的攻击英雄ID，英雄最后一击同样覆盖记录。普通单位补刀仅追溯目标的该条记录，最新英雄无效则流失，不回溯更早攻击者或玩家的新契约。召唤物归属有效英雄主人，塔补刀不追溯。
- 保留战局升级时，旧有效BUFF按原代数和剩余时间比例转换到新时长，历史积分不回算；旧战局的独立刷新时钟初始化为开局时间轴上下一个600秒节点，不补发历史精英。该迁移支持原样回滚，不改变账号及战局schema。
