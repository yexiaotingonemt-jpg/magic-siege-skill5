# 魔法王座 v0.5.3

客户端和服务器统一为0.5.3，战斗兼容版本0.5.0，协议3。本版在最新main的0.5.2基础上实现强化交互调整，保留手动拉取客户端、严格发布版本校验、服务端增量热更及GitHub来源校验。

## 玩家可见调整

- 升级后只更新战场右下角的“技能强化”图标，右上角角标显示当前职业剩余选择次数。点击图标后打开选卡窗口，支持连续处理积攒的强化。关闭窗口、再次升级、刷新或重连均不会自动弹窗；候选及次数保留，选完后入口隐藏。
- 放大卡片的技能名称和强化词条名称，在技能名称后增加独立的感叹号按钮。可查看当前技能效果、冷却与体力消耗、该技能已选强化和次数，以及通用强化；查看和返回不会触发选择或消耗次数。
- 详情内数字键不执行选卡；Esc先返回选卡，再关闭窗口。连续键盘选择后正确恢复焦点，失败时保留重试入口；支持桌面与窄屏，强化图标和详情按钮保留实际触控尺寸。

## 更新及部署

退出游戏，在Fork或GitHub Desktop切换到main并执行Pull，保留完整仓库，再运行根目录的“魔法王座.exe”。客户端不自动下载更新，旧客户端由服务器提示手动拉取。

服务端从已合入GitHub main的同一批源码生成包，默认使用`--battle preserve`增量热更。上线前备份账号；激活时重新验证GitHub来源、文件内容及相对线上提交的继承关系。正式部署结果、测试数量及回退目录将在验收记录中补充。

## 发布前验证

- Windows逻辑测试462项通过，3项Linux专属测试跳过；完整浏览器回归29项通过，涵盖桌面与390px窄屏。
- 最终0.5.3完整桌面包6项测试通过，覆盖手动强化、只读详情、登录资料保留、严格版本限制和取消自动下载。
- 根目录真实启动器成功准备隔离运行环境；13份仓库启动清单文件逐一校验，5份预构建文件与完整桌面包逐字节一致。使用准备后的实际运行环境验证升级不弹窗、积攒3次、详情不误选、选择后扣减及刷新保留候选通过。
