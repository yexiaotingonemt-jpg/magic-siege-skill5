# 0.5.3：修复仓库 EXE 启动后窗口隐藏

修复 Windows 仓库启动器向 Electron 游戏进程传递 `SW_HIDE`，导致页面已加载却没有可见窗口的问题。游戏本身为 GUI 程序，不需要隐藏控制台；移除该启动标记即可正常显示。

原有自动测试通过 Playwright 直接启动 Electron，未覆盖 Go 仓库入口的原生窗口状态。现增加真实运行仓库 EXE 的回归检查：使用隔离缓存与用户目录，确认系统中出现标题包含当前发布版本的可见游戏窗口，并在结束后只关闭本测试的进程。

客户端与服务器统一为 0.5.3，战斗兼容保持 0.5.0、协议保持 3。客户端仍要求手动拉取，不恢复自动更新。服务端本次仅同步发布版本，可使用 `--battle preserve` 增量发布，保留当前战局。
