# 0.6.1 友军靠近与技能详情

客户端和服务端统一发布为0.6.1，战斗兼容版本保留0.6.0，协议3。

- 点击友军先朝其当前位置移动，抵达自身普攻距离后重新警戒索敌；不追击友军的敌方目标，抵达后不会持续跟随，再次点击可重新靠近。
- 技能栏详情仅展示对应技能与全部升级项，已获得白色、未激活灰色；新增基础属性和通用效果入口。
- 随仓库提交配套预构建客户端，玩家退出游戏、拉取main后重新启动。

本次增加的靠近状态是可选单位字段，已有单位在下一次点击友军时初始化，不依赖重建战局。引导层、账号结构、战局schema及兼容标记保持一致，使用默认preserve热更。保留现有玩家、英雄、成长、积分、冷却和战局计时，旧客户端连接会因发布号升级而要求重新拉取。

发布前验证：563项逻辑测试通过、3项Linux专项按平台跳过；11项浏览器交互测试通过，包含桌面和390像素窄屏。桌面包与仓库清单校验、正式热更读回结果另记部署验收。
