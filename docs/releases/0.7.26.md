# 0.7.26 森林精灵共生链接续时

客户端和服务器统一发布为0.7.26，战斗兼容0.7.0、协议3保持不变。使用保留战局热更。

- 森林精灵2技能共生链接从生效时持续8秒。
- 链接任一端每次实际恢复生命大于0，对应链接剩余时间增加3秒，最多8秒；包括被动治疗。满血空疗、禁疗、死亡、超距和过期链接不续时。
- 共享治疗不重复续时、不递归传播。多目标链接分别计时，治疗精灵时延长其有效链接，治疗被链接友方时只延长对应链接。
- 链接附带的减伤、攻速强化同步续时；原始治疗、共享比例和统计归属保持既有规则。
- 按新配置重新运行五职业90组同等级评价参考样本，每组实际消耗21点体力；六个共同参考节点变化最高1.33%，同步更新评价参考曲线和配置指纹。积分公式与计分系数不调整。

验证：940项单元测试通过，3项Linux测试跳过；8项原生桌面回归通过；客户端构建、16个启动文件与4个运行时分片哈希、保留战局及回滚预检通过。新增用例覆盖续时上限、有效/无效治疗、多目标、被动治疗、共享不重复、增益同步和自然到期。

`npm run test:balance`的旧规则标准门禁通过（总分/KDA相对均值±10%、承伤积分占比小于20%），但仍有19组策略排序、1组正常总分优势未达项及4组高频单技能总分更高。该入口使用旧规则，不覆盖本次新链接。另用当前引擎在5/20/40级比较不施法、最佳单技能和正常策略，并复验90组评价参考样本；当前规则在该受控参考场景的跨职业总分/KDA尚不满足±10%，不是本次上线新增的全面平衡结论。本次按用户指定规则实施，不扩展修改其他职业或拟合计分系数。

完整原始统计、对照、构建包和发布验收保存于`E:/Codex/Support/魔法王座/elf-link-release-20261105`。正式服务器验收另行归档。
