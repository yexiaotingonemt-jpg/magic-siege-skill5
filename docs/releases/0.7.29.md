# 0.7.29 共生链接跨次保留与独立计时

客户端与服务端统一发布为0.7.29，战斗兼容0.7.0、协议3保持不变，保留0.7.28升级体力消耗翻倍规则。采用保留战局热更。

- 森林精灵再次释放2技能时保留已有链接，每次新增的每条链接独立持续8秒；允许跨次重复连接同一友军。
- 每次自动选择12格内当前生命绝对值最低的1名合法友军，不排除已链接者，不受手选覆盖。生命相同时按距离、单位ID排序；同次多个名额选择不同对象。
- 「链接目标增加」只有1档：每次额外连接1人，每次最多选择2名友军；已有旧2档构筑的有效效果按新1档上限计算，历史升级消耗保留，后续不再出现该强化的第二档。
- 每条链接分别共享42%有效治疗，重复链接分别结算；主动或被动有效治疗使所有对应的有效链接各续3秒，各条剩余时间仍最多8秒。共享治疗不递归、不重复续时。
- 新施法不刷新旧链接，某条到期不影响其他链接。减伤、攻速沿用同类增益规则，伤害平摊按实际单位去重，重复链接不把同一人算作多名成员。
- 状态图标展示链接条数，详情列出各条独立剩余时间；旧构筑的强化档位显示遵守当前上限。

回归覆盖最低当前生命选择、范围/排除自身、跨次重复、强化上限与旧档位、独立到期、重复共享、真实被动治疗、真实10秒冷却重放、强化及平摊。60秒1200次被动治疗压力场景逐次验证每条剩余时间不超过8秒。
