# 0.7.1排行榜折叠与契约记录

目标两端发布号0.7.1，战斗兼容0.7.0、协议3、战局schema3、账号schema1。该分支准备客户端及服务端共同更新，尚未合并或发布正式服；正式服保持0.7.0。

## 玩家看到的变化

排行榜默认只显示姓名、总积分和KDA，阵营、职业及机器人／在线状态收进契约记录面板。全部玩家名称带下划线，包括「契约者9」；点击姓名可查看本人或其他玩家的本局记录。侧边榜与底部「排行」入口行为一致。

契约按新到旧排列，展示职业、等级、起止时间、持续时间、结束原因、本次总积分、KDA与消耗体力；展开贡献明细可查看有效伤害、原始承伤、有效治疗、小兵击杀生命量、英雄击杀／助攻及体力的原始值和对应积分。当前契约每3秒更新，保留已展开项目和滚动位置；面板关闭后停止查询。支持键盘关闭、焦点返回、空记录、失败重试及新战局提示。

## 记录与性能

- 新增已登录可读的分页接口`GET /api/contract-history?playerId=...&before=...`，每页最多20条，校验客户端版本及参数。客户端按需查询，不把完整历史放进每200ms的战斗快照。
- 从更新生效后按玩家ID保存本局所有已结束契约，独立于旧全局100条报告截断；同名玩家不串记录。死后弹道等补计继续更新原契约报告，结算保持幂等。
- 原战局热更时尽量恢复旧版仍有的全局最近100条。更早已丢弃记录无法补回；恢复数据标记不完整，不将可恢复数量宣称为本局真实契约总次数，不伪造起点或持续时间。
- 清榜保留单次契约原始记录，排行榜累计值从清除时重新计；面板明示两者区别。战区重建归档存活英雄，记录留在本局；重开本局／进程重启后清空。
- 此次只增加查询、归档及展示，沿用既有积分与KDA口径；技能数值、成长、计分系数及积分发放逻辑没有调整。同步修正新版排行说明中的旧KDA公式。
- 新字段均可在旧战局中延迟初始化，未修改固定引导文件，保留战局更新无需冷重启；正式部署仍须按现有来源校验及发布流程验证，不据此记录宣称已部署。
