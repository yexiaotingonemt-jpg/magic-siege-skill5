# 0.6.3 职业被动与清除排行榜验收

本次从已发布0.6.2源码独立接入五职业固有被动、被动查看入口及超级账号清除排行，不发布本地整套新版主动技能、成长或KDA草稿。用户已明确授权同时发布这两项。

正式服务默认启用职业被动。新增配置与字段均可兼容旧内存，保持GAME_VERSION=0.6.0、PROTOCOL_VERSION=3、运行schema2、账号schema1，发布号两端0.6.3。保留战局迁移测试确认英雄、成长、计时、已有积分和待执行闭包引用保留；历史积分不按新系数重算。清榜在隔离双客户端环境验证，正式部署验收不执行真实清榜。
