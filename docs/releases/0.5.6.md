# 魔法王座 v0.5.6

客户端与服务器统一为0.5.6，战斗兼容版本0.5.0、协议3保持不变。没有改变战局对象结构或技能前摇闭包接口，支持保留战局热更；旧客户端按发布号校验拒绝连接。

- 所有职业均可点击20格内敌友单位；选择敌人后自动移动并在普攻射程内攻击。
- 选择友军时追击其当前攻击的敌人；友军切换目标后随之更新。目标死亡、越界或不再可攻击时清除选择并按警戒规则重新索敌。
- 技能按选中对象或其一层攻击目标解析阵营；目标无效、类型不符、超距或不满足原技能条件时提示，不回退其他对象，不扣体力、不进入冷却。
- 自身增益、群体技能的中心与人数、前摇锁定、控制和防守移动边界继续遵守原规则。

玩家退出游戏，在GitHub Desktop或Fork切换到main并拉取完整仓库，再双击根目录魔法王座.exe。客户端不自动下载更新。
