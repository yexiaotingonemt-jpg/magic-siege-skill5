# 0.5.7 界面优化

客户端与服务器统一发布为 0.5.7，战斗兼容版本保持 0.5.0，协议保持 3。

- 三选一强化显示所属技能编号和名称，按技能1、2、3、4排序；相同技能保留抽取时的随机顺序，通用强化排在最后。
- 强化选择、技能详情、已选强化及待选入口统一深绿底、古铜细边、米白文字；优化桌面三列和手机纵向卡片布局。
- 取消战报入口和面板，底部导航保留战场、技能、排行。实时积分/KDA排行固定在战场左侧，常驻展开。

本次仅包含上述界面调整，不包含其他工作区中尚未发布的积分、助攻、出兵配置及性能日志修改。服务端采用保留战局热更，账号、当前战局、成长、体力和积分保留。玩家退出游戏、拉取完整仓库后重新启动。
