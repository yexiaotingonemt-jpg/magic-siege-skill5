# 0.7.8 周围目标分页

客户端与服务器统一发布号为 0.7.8，战斗兼容版本保持 0.7.0，协议保持 3。以 0.7.7 发布提交为基线，只加入目标信息面板交互，不调整战斗规则与数值。

## 界面变化

- 点击战场单位时，右上角同时收集该单位及周围4格内的存活士兵、英雄和防御塔。点中单位排第一，其他目标按距离排列。
- 横向分页标签支持点击、方向键与 Home/End 切换。切换详情沿用手动锁定或待契约选择，保留本次点击的目标列表；再次点选战场单位重新收集。
- 属性随快照更新，离场标签自动移除；当前目标离场、点击空白或按 Escape 时关闭面板。
- 未契约时保留确认弹窗，并避让目标信息面板；多目标标签可横向滚动。

## 发布前验证

- `npm run build` 通过，客户端包与仓库预构建文件均使用0.7.8。
- `npm test`：873项，870通过、3跳过、0失败。
- 桌面1440×1100、窄屏390×844的分页与锁定交互、生命刷新、死亡移除、超过5个目标、契约确认和版本门禁共10项浏览器验证通过。
- 另有3项已有浏览器用例失败：符文战车旧技能效果标签断言1项、精灵旧连接机制断言2项。在未修改的0.7.7提交4b6f582上复现了相同失败，本次未调整这些规则或旧测试。

按统一发布约定经PR合入main后，从已推送提交打包服务端，使用`--battle preserve`保留战局，并独立核对GitHub来源、账号备份、版本接口、旧版拦截、登录及SSE。实际激活结果、SHA-256与回滚目录记录在E盘发布辅助目录。
