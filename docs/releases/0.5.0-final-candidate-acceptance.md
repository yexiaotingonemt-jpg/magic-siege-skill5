## 数值证据与限制

独立任务完成90类词条效果对照、500次合法1→40构筑、816组阵容对照和60分钟模拟。816组的原始JSON已保存在Git，明确标注其基线为首次提交 `ccfbc7c`，用于保留数值证据，不冒充最终包的重跑数据。完整脚本、浏览器/EXE日志及原始证据在本机 `evidence/independent-v050/`；最终包专项在 `evidence/final-candidate/`，5项EXE回归在 `evidence/packaged-final/`。这些本机目录不随Git上传。

当前结论是实现和候选包验证通过，仍需真人长局校准。满构筑火法/战车的爆发和领主免疫、火盾时机相互影响，脚本对照不能转换为玩家胜率。初始100体力通常只支持15—17级；手机长广播、密集状态重叠与横屏滚动保留为P3体验改进。未覆盖全部词条组合、弱网多人压测、实际手机硬件和正式更新链路。
