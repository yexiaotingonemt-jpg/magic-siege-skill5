# 0.7.19：控制出口突发并公平发送实时数据

0.7.17完成差量同步，固定战场回放稳态流量降低92.37%；0.7.18补齐大HTTP状态响应压缩。公网压力测试显示，集中读取完整状态并建立连接时，仍可能出现1.3秒的单次同步间隔，渲染约60 FPS而显示时钟停顿701毫秒；仅降低总字节量未消除突发发送对其他连接的影响。

0.7.19在压缩之后对大JSON响应和SSE统一安排发送节奏：默认总预算128 KiB/秒，每次最多1 KiB，不同连接轮流发送。大响应不会一次占满发送队列，小于1 KiB的普通JSON响应直接返回；HTTP操作确认不等待大状态响应。遵守底层socket排空信号，断开的连接释放任务；慢连接仍按0.7.17的基准补发最新状态。

预算作用于本游戏当前运行时，不改服务器全局网络设置，也不改变模拟、操作、快照目标频率和玩家资源。128 KiB/秒是本部署为降低出口突发预留的应用发送预算，不是对云服务器套餐带宽的认定；大量在线玩家的容量需要另行实测。

回归覆盖字节顺序、轮转公平性、小实时响应不等待另一连接的大响应、断开释放、真实Gzip/本地代理、背压与暂停恢复。两端统一0.7.19，兼容0.7.0、协议3、战局schema3、账号schema1不变，保留战局预演通过。正式公网多连接和真实桌面连续采样结果见配套发布验收。
