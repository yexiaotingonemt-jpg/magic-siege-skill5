# 0.7.13 契约职业切换与界面精简

日期：2026-11-03。客户端与服务端统一发布号为 **0.7.13**，战斗兼容标记 **0.7.0**、协议 **3** 保持。

- 修复点击“森林精灵”时难以切换的问题。原先每次战场快照都会重建职业按钮，鼠标按下后若收到同步，按钮被替换导致点击失效。现在只在可选职业变化时创建按钮，正常同步仅更新选中状态，并保留键盘焦点。
- 增大职业按钮点击区域，提供明确的选中状态。
- 删除契约弹窗内重复的附近单位列表；统一通过上方目标分页切换单位，弹窗仅显示当前单位及其可选职业、取消与确认契约操作。
- 采用 `--battle preserve` 发布，保留当前战局、进度与登录会话。玩家退出游戏，在 GitHub Desktop 拉取完整仓库后，重新启动根目录的魔法王座.exe。

回归覆盖桌面1440与窄屏390：鼠标按下期间接收多次真实服务器快照、森林精灵点击与键盘切换、不同兵种分页切换、职业选项显隐，以及最终契约指定单位为森林精灵并仅扣除3体力。

发布前验证：893项单元、HTTP及热更测试通过，3项Linux专用检查跳过；11项浏览器检查、8项打包后Windows桌面检查通过。构建、桌面打包和仓库客户端16个启动文件、4个运行时分片的SHA-256校验通过。
