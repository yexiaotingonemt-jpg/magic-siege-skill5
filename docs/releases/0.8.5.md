# 0.8.5 领主驱散范围与随机契约规则

- 黑暗领主击杀触发的驱散只寻找当前普攻范围内的敌人，包含射程边界，并随普攻距离强化变化。每次选择最近一名有可驱散增益的敌人，随机移除其1个增益；范围内没有合法增益时不保留机会，自身净化与回血照常结算。
- 随机契约优先选择剩余血量百分比最高的己方合法普通士兵；最高比例并列时随机选兵，再随机选择其可契约职业。
- 两端统一发布号0.8.5，战斗兼容0.7.0、协议3沿用。使用服务端保留战局热更，不重开本局。

验证：领主范围及现有规则57项相关测试通过；随机契约桌面和窄屏3项浏览器回归通过。600组旧版平衡基准标准项通过，修改前后原始统计一致；其19组策略顺序、1组中频总分优势及4组高频单技能总分比较的既有未达项保留。旧基准不代替当前设计的完整1V3和平衡验收。
