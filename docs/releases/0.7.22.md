# 0.7.22 同等级统一KDA评价

客户端与服务器统一发布号0.7.22；战斗兼容0.7.0、协议3、战局schema3、账号schema1保持。

- 所有职业共用同一条等级评价曲线，不为职业单独设置门槛；同等级、同KDA评价完全一致。
- 同级达成率＝本次KDA／本次结算等级的标准KDA。达到80%为C合格、100%为B良好、120%为A优秀、150%为S卓越，其余D待提升。
- 结算与契约历史展示参考等级、基准KDA及达成率；历史记录按原结算等级评价，死后追加贡献仍归属原记录。
- 保留战局更新后，旧结算提示从原战报按等级重新计算显示；缺失等级或对应规则尚无基准时不套用固定分数档位。重算仅影响显示，不修改原积分、经验或强化次数。

等级基准来自0／5／10／20／30／40级的90组受控引擎样本，五职业等权汇总，每组实际消耗18点施法体力＋3点契约体力，中间等级线性插值。0级基准139.20、40级605.37；例如KDA200在0级为A、40级为D。计算使用未取整数值。模型范围、六个节点、配置指纹和校准记录见[计分规则](../rules/12-ratings-and-scores.md)。这是展示参考，不代表职业或阵营平衡已验收通过。

已完成同等级全职业一致性、等级边界、死后追加贡献、旧结算快照、差量同步与保留战局预检。配套仓库预构建客户端同步更新；玩家退出旧游戏后拉取完整main，再运行根目录魔法王座.exe。正式服激活和登录／SSE验收另见部署记录。
