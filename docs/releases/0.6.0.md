# 0.6.0 连携技能与通用强化

依据2026-10-29钉钉《魔法王座技能设计》「职业技能设计5」更新五职业20个技能及词条，并重新分配强度。

- 四技能费用统一1／1／2／3体力，基础冷却6／10／22／42秒。施法经验和基础积分都按体力消耗计算。
- 黑暗领主：震荡命中自身灼烧追加伤害，冲锋紫色附带灼烧；大招技能吸血不再由普通攻击与溅射触发。
- 火焰法师：2技能为消耗1炙热的死亡标记，死亡返3层；3技能在至少3层炙热时释放三颗火球；大招消耗资源收割。
- 森林精灵：1技能治疗选中友军并伤害其附近敌人；金色链接平摊伤害，共享治疗和平摊均不递归。
- 兽人战士：1技能为非引导汲血链接，可同时移动和施法；3技能直接与所选友军换位。
- 符文战车：3技能震荡击退，4技能五次定点连轰；冰霜弹只有命中腐蚀目标才附加减攻速。
- 新增11类通用词条，每个职业共29类。通用词条的感叹号直接展示对应效果，技能图标与换位后的内容一致。
- 保留升级后手动打开强化、待选次数、玩家选中目标优先、中文提交身份及左侧常驻排行。

完整倍率、时间、人数、逐次强化和叠加规则见[当前规则与平衡依据](../rules/15-traits-and-elites.md)。可调静态字段见[数值配置表](../数值配置表.md)。

## 更新方式

退出游戏，在Fork／GitHub Desktop拉取main，保留完整仓库，再运行根目录「魔法王座.exe」。无需安装依赖或自行构建；旧版会收到更新提示。没有仓库的成员可下载[0.6.0完整仓库ZIP](https://github.com/yexiaotingonemt-jpg/magic-siege-skill5/archive/refs/tags/v0.6.0.zip)。

本次同时提升战斗兼容版本为0.6.0，账号与登录会话保留，发布时明确重开战局，以新版技能开始新的成长与构筑。协议仍为3；不将旧版待执行技能和持续状态带入新战局。

## 平衡验证口径

[同为4体力的受控技能对比](0.6.0-rotations.json)中，五目标领主连携实际伤害为5150%攻击，重复1技能为4000%；战车分别为3900%和2400%。单目标战车仍可按场景优先维持腐蚀，控制技能不要求强行加入每轮输出。火法测试包含一次真实死亡标记，结果需结合资源生成和剩余炙热理解。

[同级2／3人小队对领主](0.6.0-balance.json)覆盖6个等级、3个随机种子，共36场。测试不含塔和兵线支援，体力1000以排除断粮，采用真实可选次数组成随机构筑；结果不能当作正式玩家胜率。
