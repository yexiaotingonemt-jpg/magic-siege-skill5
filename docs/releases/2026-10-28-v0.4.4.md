# 0.4.4：GitHub 仓库直接运行

客户端、服务器统一发布号为 `0.4.4`，共同战斗兼容标记为 `0.3.1`，协议为 `1`。本次发布增加固定的仓库根目录启动 EXE、预构建页面和可复用的运行环境分片。

同事完整拉取 GitHub 仓库后，双击根目录 `魔法王座.exe` 即可运行。已有客户端优先使用本机已拉取、完整且版本一致的仓库；没有对应本地版本时仍可使用服务器签名更新。

运行环境放在被 Git 忽略的本机缓存，用户资料仍放在用户目录，运行无需 node_modules。发布与使用方式见[GitHub 客户端分发](../GitHub客户端分发.md)。

本版本完成了仓库启动入口的首次推送，但未切换正式服；准备期间另一项已授权发布将正式服升级为 0.4.5。仓库分发内容随后对齐 0.4.5 和战斗兼容标记 0.3.2，未回退服务器，详见后续版本记录。
