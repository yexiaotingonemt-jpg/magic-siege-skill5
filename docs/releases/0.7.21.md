# 0.7.21 阵亡后强化与单次KDA评价

客户端与服务器统一发布号0.7.21；战斗兼容0.7.0、协议3、战局schema3、账号schema1保持。基于已上线0.7.20发布。

契约期间继续累计经验、等级、基础属性及强化次数，但不能选择技能强化。英雄本次阵亡后、下一次契约前可连续使用累计次数；重新契约后再次锁定，剩余次数、已选强化及职业归属保留。NPC同样在阵亡后、下一次契约前选择。战区重建与机器人离场不当作阵亡，不提前解锁本次新累计次数。

阵亡后显示本次KDA及评价，契约历史显示逐次评价。暂定S卓越≥150、A优秀≥100、B良好≥60、C合格≥30，其余D待提升；只展示评价，不修改积分、经验、强化次数或计分系数。当前KDA仍按本次战斗积分／max（本次实际体力，21）计算；存活时等待结算，死后追加贡献更新原评价。

新字段均为可选、延迟初始化，旧战局与已排队技能可保留。配套客户端从完整main拉取后运行仓库根目录魔法王座.exe。部署验收单独记录。

发布准备验证：922项单元测试通过，3项Linux专用测试跳过；12项桌面／窄屏浏览器用例、8项打包桌面用例通过。0.7.20→0.7.21真实配置保留与回滚预检通过，旧待选队列、在途技能及可选结果字段兼容。16个客户端文件及4个运行时分片哈希匹配。

旧规则平衡入口标准组通过；策略顺序19组、中频总分优势1组、高频单技总分超过中频4组仍为既有未达项。该入口不覆盖当前设计整体平衡，本次未修改技能数值、品质概率或积分系数；本次发布不宣称整体平衡已通过。
