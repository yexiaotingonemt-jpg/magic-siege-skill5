# 0.7.25 黑暗领主移动动作修复

客户端和服务端统一发布为0.7.25，战斗兼容版本0.7.0、协议3保持不变。

- 修正黑暗领主侧面及前后斜面的双步循环，左右腿交替支撑、屈膝和过腿，镜像取得对应的另一侧动作。
- 步态改为按实际显示路程推进，每走2.4格完成一个双步周期；减速和停步时不继续空踩，暂停、瞬移及战斗动作不累计步行距离。
- 保持原正背面步态、显示尺寸、脚底锚点、朝向规则及攻击施法切换，不改变服务端移动速度和战斗数值。

验证包括单元测试、双方视角八方向八帧、慢走停步、暂停冻结、战斗切换及五职业契约回归。正式发布按统一版本约定准备可直接拉取运行的客户端，并以保留战局模式热更服务端。
