# 0.7.9 特殊怪物闪光与积分传递发布验证

日期：2026-11-03。客户端与服务端统一为0.7.9；战斗兼容版本0.7.0、协议3保持不变。

特殊怪物和持有积分奖励的英雄显示金色脉冲、光环及星点。击杀特殊怪物获得30秒「积分+20%」，替代原四种随机奖励；击杀仍在增益期的英雄后继承，每棒按最初设计时长减1/4，默认30/22.5/15/7.5秒，下一次击杀改为一次性200积分。传递使用当前棒完整初始时长，不受上一位已消耗时间影响。恰好1/4仍传递；过期不会获得末棒奖励。

额外积分只作用于持有期间的新增计分，固定200分不再被增幅；额外积分和末棒收益均有独立账本，进入排行、KDA及结算明细。重复领取不叠加，再次击杀特殊怪物重置首棒。已持有另一条链时，末棒200分保留该链，正常继承则替换时长及代数。倒计时、可点击状态说明、广播和重连显示一并覆盖。

从GitHub最新0.7.8建立独立发布工作区，仅迁入本功能，保留线上已有成长、阴影、技能详情及其他修复；原工作区的其他未提交开发保留原状。

## 平衡检查及边界

`npm run test:balance` 标准门禁通过：无词条英雄优先5/20/40级标准总积分与KDA的职业偏差在±10%以内，标准承伤积分占比小于20%。既有诊断仍有19组策略排序未达、1组正常中频总分未高于单技或不施法、4组高频单技总分高于中频。没有为了消除这些诊断而改动职业系数、技能或测试门槛。

该旧入口使用固定8/3/2/1调度和旧KDA口径，不包含特殊怪物；它不代表当前稿同额实际体力、完整词条、全职业±10%及不施法≤80%门禁通过。当前稿仍标记待平衡。本次奖励按用户指定的20%和200分实施；专项覆盖所有计分种类、既有积分不回溯、末棒不乘20%、重复结算防护、召唤归属及地图重建。
