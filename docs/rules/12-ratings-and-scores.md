# 贡献、积分与KDA

目标0.7.0，与当前钉钉计分规则同口径：

B＝a(D＋M)＋bT＋cH＋200K＋100A；P＝100S＋B；KDA＝B／max(S,21)。

D为有效伤害（含护盾吸收），M为击杀小兵最大生命之和，T为减免前原始承伤，H为有效治疗，K／A为英雄击杀／助攻，S为实际消耗的契约及施法体力。过量伤害和过量治疗不计；失败操作或补充体力不计。纯保护不新增个人计分项目，反伤、治疗转伤及召唤归属于原施法者。

排行榜读取服务端P、B、S和KDA，不再用总分除体力覆盖新公式。清榜仍仅允许超级账号，经确认后全部玩家累计值重新统计，保留英雄、成长与战局。

系数逐项来自当前源表，本次未自行拟合新系数。公式正确与职业公平是独立验收；当前源码不宣称±10%公平、承伤＜20%或不施法≤80%已通过。

### 单次契约评价（2026-11-03）

英雄结算后按本次契约的KDA给出评价，不使用排行榜累计KDA。当前规则仍为本次战斗积分除以 max（本次消耗体力，21），仅用于展示，不增加积分、经验或强化次数。暂定阈值如下，按未取整KDA比较：

| 评价 | 本次KDA |
|---|---|
| S · 卓越 | ≥150 |
| A · 优秀 | ≥100且＜150 |
| B · 良好 | ≥60且＜100 |
| C · 合格 | ≥30且＜60 |
| D · 待提升 | ＜30 |

阵亡后战场显示本次KDA及评价，契约历史保留每次评价；正在进行的契约显示“结算后评价”。死后弹道或持续效果追加贡献时同步更新原结算评价，不重复结算，也不影响其他契约。经典规则仍按其原有单次总积分除以实际体力计算KDA，无有效分母时不评价。

### 闪光积分增益（2026-11-03）

特殊怪物奖励统一改为30秒「积分 +20%」，仅对增益有效期间新增加的各项积分生效；额外部分写入 `eliteScoreBonus`。击杀持有者按初始时长每棒递减1/4继承，第五棒固定获得200积分，写入 `eliteScoreBounty`，不被积分增益放大。两项均进入玩家总积分及英雄结算明细，不改原始战斗统计。详见[特殊怪物与奖励](15-traits-and-elites.md#精英兵与奖励)。
