## 12. 贡献评价、积分与排行

### 12.1 统计口径

| 指标 | 定义 |
|---|---|
| 原始承伤 | 实际有效命中的护甲、减伤和护盾结算前伤害。 |
| 对英雄/小兵/建筑伤害 | 实际扣除生命与实际护盾吸收之和，不含过量伤害。 |
| 对非建筑单位伤害 | 对英雄及小兵的有效伤害合计。 |
| 击杀及助攻 | 亲自击杀英雄、小兵或摧毁塔，以及满足窗口的助攻次数；与“支援助攻”单独统计项区分。 |
| 有效治疗 | 实际恢复的生命，不含过量治疗。 |
| 有效护盾吸收 | 实际被护盾吸收的伤害。 |
| 支援助攻 | 英雄、小兵或塔死亡时，最近10秒伤害死者，或为击杀来源提供有效治疗的其他存活英雄记一次。 |
| 存活时长 | 从本次契约到阵亡或地图重建结算之间的战斗时间。 |

伤害、治疗及支援只计入各自归属英雄。助攻只结算给满足记录窗口且此时仍有存活英雄的其他玩家，不与同一击杀者重复。有效治疗写入支援来源记录；仅施加护盾、减伤、净化或换位不单独建立该记录。

### 12.2 职业评价

| 职业 | 参与指标及权重 | 指标达到100分的基准 |
|---|---|---|
| 兽人战士 | 原始承伤35%；对英雄伤害35%；支援助攻30% | 6000；5000；10次 |
| 符文战车 | 对建筑伤害65%；对非建筑单位伤害20%；击杀及助攻15% | 6000；7000；16次 |
| 黑暗领主 | 存活时长40%；击杀及助攻40%；对英雄伤害20% | 60秒；16次；5000 |
| 火焰法师 | 对小兵伤害55%；对英雄伤害25%；击杀及助攻20% | 8000；5000；16次 |
| 森林精灵 | 有效治疗70%；支援助攻30% | 6000；10次 |

```text
单项分 = MIN(100, 指标累计值 ÷ 该指标基准 × 100)
英雄评价 = SUM(单项分 × 指标权重)
本次英雄评价积分 = 300 × 英雄评价 ÷ 100
```

权重按表内百分比参与乘算，所有职业评价上限100。英雄阵亡、机器人退场或地图重建时生成本次英雄战报及评价积分。

英雄结算后，其已发出的弹道或持续效果继续产生归属统计时，更新原英雄战报，按新旧评价奖励差值补计积分，不另生成一份完整奖励。

### 12.3 总积分、KDA 与排序

战斗界面的总积分沿用 12.2 的职业评价公式：每次契约的各项贡献按职业基准归一化、单项封顶100分，再按职业权重加权。本次契约最高100分；玩家总积分为历次已结算英雄评价之和，加上当前英雄的实时评价，跨职业累计。存活时长按当前战斗时间实时计算。

```text
总积分 = 历次已结算英雄评价之和 + 当前英雄实时评价
累计消耗体力 = 成功契约费用 + 成功施法费用
KDA（积分性价比） = 总积分 ÷ 累计消耗体力
```

未消耗体力时 KDA 显示“—”；已消耗但贡献为0时显示0.00。失败操作及不耗费体力的技能二段不增加消耗；补充体力不减少历史消耗。阵亡、切换职业、阶段或地图重建后仍保留同局累计值；新战局从0开始。英雄结算时将实时评价转为已结算累计值，不重复加分；结算后在途效果的贡献按评价变化差值补计。

旧奖励积分 `score` 继续记录施法奖励、评价奖励（按300分上限换算）和阶段胜利奖励，供既有奖励逻辑使用；它不参与本次贡献排行、总积分或KDA。

排行榜包含本战局未退役的玩家及机器人，离线玩家保留。按未取整总积分倒序，同分保持玩家列表顺序。战斗画面左下方默认展开实时榜，可收起、滚动；底部“排行”打开完整榜单并说明公式。本人高亮，显示阵营、职业、总积分和KDA。总积分显示1位小数，KDA显示2位小数；服务端快照统一提供实时总积分、累计消耗与KDA。

战报仍显示最近15条英雄结算记录、评价、奖励及各项指标分解；阶段结果另记录双方胜场。
