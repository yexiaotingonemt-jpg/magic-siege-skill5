# 贡献积分与排行

[玩法模块总览](README.md) · [代码模块索引](../architecture/README.md)

本地规则修订：2026-10-29线性贡献积分。正式发布状态以发布记录为准。



`总积分 P = a×D + b×T + c×H + d×Σ(被击杀小兵最大生命/4000) + e×Kh + f×Ah + 100×S`

`KDA = P/S`；S=0显示“—”。各次契约、不同职业的事件分别使用事件归属英雄的系数，再累加到玩家。本次契约不封顶，实时记分；结算只生成战报，不重复发放。

- D：对英雄、小兵、建筑造成的实际扣血与护盾吸收之和，过量伤害不计。伤害的分类汇总不重复计分。
- T：原始承伤，沿用当前减伤/护甲/护盾结算前口径；只有实际产生扣血或盾吸的有效命中才记录。生命费用不计承伤；完全未造成扣血或盾吸的命中不计。
- H：实际恢复生命，包括归属自己的自疗、共享治疗，不含过量治疗；护盾生成或吸收不另加治疗分。
- Kh：亲自击杀英雄数，不含击杀小兵或塔。Ah：助攻击杀英雄数；死亡前5秒内亲自造成有效伤害，或先有效治疗友军、该友军再对死者造成有效伤害（治疗与命中均须在死亡前5秒内）。治疗不要求作用于最终击杀者；治疗发生在命中之后不追溯旧命中；允许原英雄阵亡后在5秒窗口内获得归属助攻。同次死亡去重，击杀者不再拿助攻分。小兵/塔助攻没有此项奖励。
- S：成功契约及成功施法实际扣除的体力。契约3点=300分；普通技能1点=100分；大招3点=300分。失败操作、体力补充不给分。阶段胜利不再另加积分。
- 小兵含普通兵、精英兵及召唤兵；塔只提供伤害分，不提供小兵击杀分。死后弹道、持续效果及召唤物继续按原英雄职业归属记分。

## 小兵的两份收益

在没有额外护盾、回血和多人重复消耗的情况下，设小兵满血为M，则必须满足 `d(M)=a×M`。实现为 `d=4000a`，每次击杀再乘 `M/4000`。普通4000血小兵直接使用表中d；5000血乘1.25，12000血乘3。

| 行为 | 战斗贡献分 |
|---|---:|
| 打满伤害并击杀 | aM+aM=2aM |
| 仅补刀（伤害趋近0） | aM |
| 打满伤害但未获得击杀 | aM |

一个固定d无法同时对不同满血值的小兵满足上述等式，因此这里按满血值折算。这是对原先“小兵数×d”的必要细化。真实1点伤害补刀会多拿a分，符合用户的“约等于没有伤害分”。

2:1适用于战斗贡献；固定体力分单独相加。例如战士对4000血小兵：独杀277.36、纯补刀138.68、只有伤害138.68。若各消耗1点体力，总积分分别377.36、238.68、238.68，总积分比值约1.581倍，而非2倍。两条要求同时保留时数学上只能如此。
