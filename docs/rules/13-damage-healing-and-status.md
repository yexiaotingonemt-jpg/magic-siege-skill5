# 伤害、治疗与状态

血条上方的状态图标按当前玩家筛选：己方增益只显示自己施加的；减益和标记只显示自己施加的，以及敌人施加在自己角色身上的。其他玩家之间的状态不显示。敌方增益仅向拥有敌方增益驱散能力的职业显示（当前为启用新版规则或独立职业被动的黑暗领主）；森林精灵的友方负面净化不属于敌方增益驱散。相同状态先按来源筛选，再合并图标、层数和有效时长。

常驻被动也遵循上述个人筛选：只显示本人角色的职业被动及已获得的被动强化，其他友军和敌军的被动均隐藏。被动无法净化或驱散，因此黑暗领主也不显示敌方常驻被动；可驱散的敌方临时增益仍按原规则显示。此规则恢复0.7.32的显示范围，不改被动效果和强化内容。

状态底框颜色按当前玩家阵营判定：敌方增益、己方减益为红底红框；己方增益、敌方减益为蓝底蓝框。焚魂等标记按减益配色，悬停或点击仍可查看说明与层数。临时状态用圆形蓄水池表示剩余时间，不显示秒数；常驻被动保持满池。头顶图标不显示层数、等级、秒数或永久符号；层数、强化档位及永久且无法净化或驱散的说明放在点击/悬停详情中。

当前技能以[0.7.0整体核对记录](../releases/0.7.0-skill-alignment-20261102.md)及[当前五职业规则](10-classes-and-skills.md)为准；0.6.x字段与示例仅供旧规则兼容回归。

0.6.0伤害按施法攻击快照与技能局部倍率→易伤→护甲→常规减伤→塔守护与友军护塔→护盾→实际生命损失结算。常规减伤同名取最高，不同技能乘算，最终最多80%；反伤不递归。有效贡献记录实际生命损失+护盾吸收，不含过量击杀。评价中的原始承伤仍采用减免前伤害。

精灵金色链接在防护结算前平摊原始伤害，各成员结算一次防护；同一伤害不再次平摊，斩杀只作用于直接目标。

2026-11-03黑暗领主调整：灭军君临基础持续5秒，期间免疫任何伤害及负面效果。伤害免疫先于分摊、护盾与斩杀结算，不消耗护盾，也不记有效伤害或承伤；到期或君临被驱散后恢复正常。尖刺外壳基础持续5秒，同时反弹普通攻击和技能攻击，不递归反伤；与君临同时生效时仍可反伤。裂地震荡金色减疗词条使命中目标受到治疗降低50%、持续3秒，期间每次治疗都受影响，可净化且受负面免疫限制。完整数值见[黑暗领主](classes/dark-lord.md)。

治疗按减疗和受疗提升计算有效恢复及过量，过量不算有效治疗。共享治疗不再共享，护盾不算治疗。新盾不无限叠加，较小新盾不覆盖仍有效的较大盾。

可净化负面包括减速、易伤、降攻、普通腐蚀和灼烧等；焚魂死亡奖励标记独立保留。不可净化腐蚀仍受负面免疫限制。不死优先于斩杀，不死挡掉的伤害不进入蓄伤、结束不补扣。更多边界及各词条数值见[当前规则](15-traits-and-elites.md)。
