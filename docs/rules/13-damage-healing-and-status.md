# 伤害、治疗与状态

0.6.0伤害按施法攻击快照与技能局部倍率→易伤→护甲→常规减伤→塔守护与友军护塔→护盾→实际生命损失结算。常规减伤同名取最高，不同技能乘算，最终最多80%；反伤不递归。有效贡献记录实际生命损失+护盾吸收，不含过量击杀。评价中的原始承伤仍采用减免前伤害。

精灵金色链接在防护结算前平摊原始伤害，各成员结算一次防护；同一伤害不再次平摊，斩杀只作用于直接目标。

治疗按减疗和受疗提升计算有效恢复及过量，过量不算有效治疗。共享治疗不再共享，护盾不算治疗。新盾不无限叠加，较小新盾不覆盖仍有效的较大盾。

可净化负面包括减速、易伤、降攻、普通腐蚀和灼烧等；焚魂死亡奖励标记独立保留。不可净化腐蚀仍受负面免疫限制。不死优先于斩杀，不死挡掉的伤害不进入蓄伤、结束不补扣。更多边界及各词条数值见[当前规则](15-traits-and-elites.md)。
