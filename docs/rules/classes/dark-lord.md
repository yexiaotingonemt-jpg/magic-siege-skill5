# 黑暗领主

[玩法模块总览](../README.md) · [五职业索引](../10-classes-and-skills.md) · [公共施法规则](../09-skill-casting.md)

阵营与兵种：防守·近战；稳定职业编号：`3`。本页系数为技能1级，完整采用公共费用、冷却、成长和共享额度。

### 10.3 黑暗领主

**天赋：能量回血**。能量槽容量4。亲自击杀一个英雄获得4能量，击杀一个小兵获得1能量；每满4能量消耗4能量并恢复4%最大生命，保留余数。摧毁塔不获得该能量。治疗只恢复已损失生命。

**裂地震荡（1技能）**：以10格内选中的目标确定朝向。搜索该朝向前方10格扇形；方向点积阈值0.35，总夹角约139.025度。最多5名目标各承受320%攻击伤害，受共同额度限制，不附加降攻或眩晕。

**暗影冲锋（2技能）**：冲向18格内选中的目标。可将塔选作冲锋终点，但沿途冲锋伤害与击退不作用建筑。预警0.7秒后，以12格/秒沿已确定路线冲锋，移动时长至少0.1秒。

冲锋沿整段路径以3格接触半径扫掠，累计最多5名非建筑敌人各承受240%攻击伤害，并向冲锋方向的侧面推开5格。每个目标在该次冲锋中只命中一次，合法手选终点在总人数内预留名额；目标离开实际路线后不追踪弯道命中。击退受负面免疫及世界边界限制。预付400%攻击等效控制费用，伤害共用剩余额度。

冲锋结束后的普通行动进入[第6章](../06-navigation-and-targeting.md)，保留冲锋终点位置，不因推进边界瞬间回弹。

**焚身壁垒（3技能）**：为自身附加6秒火焰盾，受到伤害降低35%。持续扫描周围5格，每次最多选择5名可受负面状态的敌人，附加6秒灼烧；各目标每秒受到40%施法攻击力伤害。该技能不生成吸收伤害用的独立生命护盾。

火焰范围跟随领主普通移动及冲锋路径。每次扫描上限5人，不限制整个持续时间累计只能感染5个不同目标。合法手选目标在圈内时优先，其余按距离选取；可附加于建筑。

同来源重复接触只刷新灼烧结束时间，不叠层、不重置下一次跳伤时间。目标离开范围后继续灼烧；净化移除灼烧，但仍在火焰范围内可被重新附加，负面免疫阻止附加。火焰盾结束或领主死亡时停止新增感染，已附加灼烧仍持续至到期或额度耗尽。全部目标灼烧与自身减伤共用一次额度。

**灭军君临（4技能）**：释放时清除自身已有负面，并取得15秒负面免疫。期间保持普通移动和普攻；每次普通攻击对主目标周围4格内最多4名其他敌人产生总计1200%攻击的附加溅射，由实际受击人数均摊，优先英雄。主目标的普通攻击独立结算，不参与该组溅射均摊。

释放时预付1200%攻击等效免疫费用，1级剩余最多4800%攻击等效可用于全部溅射。额度耗尽后停止附加溅射，负面免疫仍保持至15秒结束。
