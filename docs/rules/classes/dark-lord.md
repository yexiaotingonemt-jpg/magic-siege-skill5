# 黑暗领主 · 当前技能设计

以2026-11-03用户确认的设计及[当前技能配置](../../../shared/current-design-data.js)为准。裂地震荡基础最多命中5人，新增紫色目标增加词条；现有减疗、尖刺反伤与君临免伤保留。正式服部署状态独立记录。

## 职业被动

每击杀1名英雄或累计3名小兵，随机清除自身1个负面状态及敌方1个增益状态，并恢复最大生命2%的生命。

## 结算说明

裂地震荡基础最多命中5人，目标增加词条分别提升至6/7人，受前方扇形与8格射程限制；主目标优先占用名额，返回波仅作用于首段命中目标。减疗为首段命中施加的持续减益，不消耗于单次治疗。

尖刺外壳的反伤基数为攻击者本次来袭时的攻击力，不是其造成的伤害量；降攻词条在读取反伤基数后施加。尖刺与君临同时生效时，普攻或技能攻击仍可触发尖刺反伤。

君临期间免疫普攻、技能、持续伤害、反伤、建筑伤害及斩杀伤害；免疫在护盾吸收与伤害分摊前结算，不消耗护盾、不记录有效伤害或承伤。持续时间强化仍使尖刺和君临分别延长至6/7秒；到期或君临增益被驱散后恢复正常伤害结算。
