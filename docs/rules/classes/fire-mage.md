# 火焰法师

[玩法模块总览](../README.md) · [五职业索引](../10-classes-and-skills.md) · [公共施法规则](../09-skill-casting.md)

阵营与兵种：进攻·远程；稳定职业编号：`4`。本页系数为技能1级，完整采用公共费用、冷却、成长和共享额度。

基础攻击力为340（上调50%）。以下技能系数沿用现值，伤害、治疗与共享收益额度使用调整后的攻击力计算；等级属性成长见第11章。

### 10.4 火焰法师

**炙热**：由技能产生的自身资源，最多5层，持续15秒。新增层数刷新整体结束时间；到期清空全部层数。

**烈焰冲击（1技能）**：在9格内优先合法手选敌人，否则选择最近敌人，固定单体承受1600%攻击伤害。释放效果增加1层炙热。

**炙热火球（2技能）**：在12格内优先合法手选敌人，其次有效当前攻击目标，再按英雄、小兵、塔类别及同类最近选择。主目标承受1600%攻击伤害。释放结算时自身炙热至少3层时，在主目标周围3格选取最多4名其他敌人，均摊400%攻击的额外伤害。本技能不消耗炙热。

**焚魂烙印（3技能）**：在9格内优先合法手选敌人，否则选择最近敌人，固定单体承受1600%攻击的一次伤害，并记录5秒死亡标记。标记期内目标被任何人击杀，存活施法者增加2层炙热；直接击杀也触发。标记用于记录击杀奖励，不按负面状态处理，不被净化或负面免疫删除。

**天火审判（4技能）**：从19格内选取当前生命绝对值最低的敌人，基础1个目标，每2层炙热增加1个目标，当前最多3个。符合范围的手选敌人优先占用一个名额，其余按最低当前生命补足。每名目标各受1600%攻击伤害，全部目标共用大招额度。释放时扣除按下技能时记录的全部炙热，不只消耗有效整组层数；前摇期间新获得的炙热保留。
