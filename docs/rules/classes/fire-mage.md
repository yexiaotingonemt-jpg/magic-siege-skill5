| 技能 | 基础效果 |
|---|---|
| 烈焰冲击 | 对选中目标造成800%攻击伤害，获得1层炙热。 |
| 炙热火球 | 普通火球800%攻击；达到3层热量时主伤1200%，周围最多3人各受150%。 |
| 焚魂烙印 | 主目标800%攻击，标记5秒；目标阵亡为存活施法者提供2热量。 |
| 天火审判 | 消耗施放时热量，每2层增加1个全额目标，每人2000%攻击；基础1个全额目标。 |
