## 兽人战士

前排守护：单体重击、群体减伤、换位救援，蓄伤转盾。基础重击不附带易伤。

| 技能 | 基础效果 |
|---|---|
| 破甲重击 | 对选中的单体造成800%攻击伤害。 |
| 守护战吼 | 自身及3名其他友方减伤25%，持续5秒。 |
| 换位救援 | 与正被敌方英雄攻击的友方换位，自身减伤35%，持续4秒。 |
| 蓄伤壁垒 | 蓄伤5秒，记录自身实际承伤，最多为最大生命60%；结束全额转为8秒护盾。 |
