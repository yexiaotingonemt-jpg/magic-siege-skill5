# 兽人战士

[玩法模块总览](../README.md) · [五职业索引](../10-classes-and-skills.md) · [公共施法规则](../09-skill-casting.md)

阵营与兵种：进攻·近战；稳定职业编号：`0`。本页系数为技能1级，完整采用公共费用、冷却、成长和共享额度。

### 10.1 兽人战士

**破甲重击（1技能）**：对6.5格内选中的目标造成1200%攻击伤害，并附加25%受到伤害增加，持续4秒。易伤对队友伤害同样生效，同类取最高值；产生的额外伤害计入该次破甲重击的额度。

**守护战吼（2技能）**：以自身为中心，保护自身及6格内最多3名其他友方非建筑单位，减伤40%，持续5秒。合法手选友军优先，其余按距离补足。自身不占其他3人的名额。保护者分别承伤时共同消耗本次额度。

**换位救援（3技能）**：手选14格内的其他友方非建筑单位时，要求有14格内的敌方英雄正在攻击该友军；满足条件后与该友军交换位置，未满足则直接拒绝。没有进入该手选友军分支时，在14格内优先手选敌方英雄，否则寻找最近敌方英雄，读取该英雄正在攻击的另一名己方非建筑单位作为被救者；该分支不对被救者额外验证14格距离。

没有合法敌方英雄及被救友军时拒绝释放。不可与自身或塔换位。换位时打断被救者正在执行的施法，双方位置受世界边界限制。兽人自身获得50%减伤，持续4秒；释放时预付400%攻击等效救援费用，剩余额度用于减伤。

**蓄伤壁垒（4技能）**：为自身添加5秒蓄伤记录，累计期间实际生命损失与护盾吸收的伤害总和。期间正常承伤，可移动、普攻和释放其他技能。记录到期且存活时，以累计实际承伤的200%生成护盾，护盾持续8秒；护盾实际吸收受本次大招额度限制。蓄伤期间死亡不生成死后护盾。
