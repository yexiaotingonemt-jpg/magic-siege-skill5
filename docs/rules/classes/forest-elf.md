# 森林精灵

[玩法模块总览](../README.md) · [五职业索引](../10-classes-and-skills.md) · [公共施法规则](../09-skill-casting.md)

阵营与兵种：进攻·远程；稳定职业编号：`5`。本页系数为技能1级，完整采用公共费用、冷却、成长和共享额度。

基础攻击力为272（上调50%）。以下技能系数沿用现值，伤害、治疗与共享收益额度使用调整后的攻击力计算；等级属性成长见第11章。

### 10.5 森林精灵

**灵息冲击（1技能）**：选择12格内敌方主目标，优先合法手选敌人，否则按当前攻击目标及自动规则选取。主目标承受600%攻击伤害。随后以该敌人为中心，在5格内选取最近最多3名友方非建筑单位，总计均摊1000%攻击治疗。

合法手选友军处于该治疗圈内时优先占用治疗名额；只要求其距施法者不超过20格手选距离，并在敌方受击点5格治疗圈内，不另外要求其距施法者不超过12格。可包含施法者。伤害与治疗立即结算，不为持续跳伤技能，两者共用一次额度。

**共生链接（2技能）**：链接12格内的另一名友方非建筑单位，优先合法手选友军，否则选择当前生命绝对值最低者；不能链接自身。持续6秒。

任意一端实际获得治疗时，按有效治疗的200%为另一端提供共享治疗，共享本身不再触发共享。链接不提供额外减伤，不因建立后超出原选取距离而自动断开。到期、任意一端死亡或共享额度耗尽时结束。

**献生净化（3技能）**：消耗自身当前生命10%，扣除后至少保留1点生命。在12格内选择最多3名具有负面状态的友方非建筑单位，优先合法手选友军，其余按距离补足，允许包括自身。没有合法负面目标时不释放、不耗血。

清除目标的负面状态，不额外提供治疗或受疗加成。释放时预付400%攻击等效净化费用；耗血不计为敌方伤害，不引发死亡或击杀结算。

**生命群疗（4技能）**：恢复自身及12格内最多4名其他友方非建筑单位，各960%攻击生命。自身单独占一个名额；其他名额优先合法手选友军，再按当前生命比例从低到高补足。被选对象全部满血时拒绝释放；否则只恢复实际缺失生命，所有目标共用大招额度。
