## 森林精灵

森林精灵：治疗、共生与净化。支援优先选中友方；选中敌方时改为该敌人当前攻击的友方，无有效选择时寻找合法的最低绝对血量友方。

| 技能 | 基础效果 |
|---|---|
| 灵息冲击 | 对选中敌人造成400%攻击伤害，治疗其周围最多3名友方，每人200%攻击。 |
| 共生链接 | 链接最多1名友方6秒；首条共享50%，额外链接各25%，共享不再传播。 |
| 献生净化 | 消耗当前生命10%，净化12格内最多3名有可净化负面的友方，至少保留1生命。 |
| 生命群疗 | 自身和最多4名其他友方，各恢复800%攻击生命。全员满血时不可释放。 |
