# 升级词条与精英

目标0.7.0：当前源表有104种有效词条，通用项展开为143个职业实例。全部效果、档位、品质和上限列于[各职业页](10-classes-and-skills.md)。

四技能0级可用，40次共享升级预算。每实际消耗1点体力获得100经验，包含契约和施法；失败操作、补充体力、击杀、塔伤及毁塔不提供经验。0级起步、40级封顶；升级余量保留，每升1级获得1次词条三选一机会，累计40次。经验门槛见[数值配置表](../数值配置表.md)。各档数值相对基础，不将前档复利叠加。

每逢5级（5／10／15／20／25／30／35／40）为**高级升级**，仅从紫色、金色抽取；其余32次为**普通升级**，从白色、绿色、蓝色、紫色抽取，不含金色。每张卡独立先抽品质，再从该品质未满档的词条中抽取，同轮不重复，允许三张卡品质不同。品质概率使用全职业共用权重，在本次合法品质池中归一化，避免词条数量改变品质概率。积攒后按每次升级原本的等级处理，不按领取时的当前等级重算。

客户端标题显示普通／高级升级及抽取范围；卡片分别显示品质名称，并用对应颜色标识边框、顶边和强化名称。当前白色分类为通用移动速度、受到治疗；绿色为通用攻速、普攻距离及部分基础技能伤害、治疗、减伤强化，其余沿用原品质。分类表位于 `shared/upgrade-quality.js`，仅重分品质，不修改效果、档位、ID或已有构筑。经典旧规则保留原固定蓝／紫／金节点。

满档词条退出候选；不足3种时只显示实际剩余项，不重复补卡、不跨品质池补卡。紫色由两池共享，必须保留后续另一类升级所需档位，避免普通升级耗尽高级候选或高级升级耗尽普通候选。

最终统一权重仍需按品质平均边际收益倒数校准，目前没有已验收的均值与最终概率。五品质当前均为开发占位权重1，各池内归一化；白、绿分类和最终概率均待平衡，不能当作品质强度或平衡验收通过。

升级获得的强化次数可以累积，契约期间不可使用；本次阵亡后、下次契约前才可连续选择，详见[成长规则](11-stamina-and-progression.md)。等级和基础属性仍随经验即时成长。

精英积分奖励不能驱散，不进入战斗增益驱散池。特殊怪物奖励以以下闪光传递规则为准。旧固定78／14／8次数、旧通用每档2%及旧技能连携不适用于当前技能。

## 精英兵与奖励

规则更新：2026-11-06。双方开局600秒后各生成1名精英，此后每600秒各生成1名。精英刷新独立于普通出兵波次，战区重建不重置开局时间及刷新周期。精英生命12000、攻击150、近战1.5格、间隔1.5秒、移速2、警戒5；特殊金色体型、冠饰和光环，不可契约。

精英被任意阵营的有效英雄最后一击击杀后，该英雄获得60秒「积分 +50%」。每个战斗单位只保存最后一位实际造成有效伤害的攻击英雄ID；英雄最后一击同样刷新该记录，召唤物伤害沿用英雄主人归属。普通战斗单位补刀时，只将奖励归给被击杀目标记录中的那一位英雄，不按助攻人数分配，也不受助攻时间窗口限制。有效英雄须为仍在场、存活且未退役的当前契约英雄；最新记录无效、已阵亡、离场或不存在时，BUFF流失，不查找更早攻击者，也不转给该玩家的新契约英雄。塔补刀不追溯；召唤物补刀仍归属其有效英雄主人。

积分增益只提高持有期间新产生的积分（伤害、承伤、治疗、击杀、助攻及体力消耗计分），不回溯此前所得。同种增益不叠加，再次击杀精英刷新完整60秒并重置传递代数。额外加分和末棒奖励计入总积分、KDA及英雄结算明细，不修改原始战斗统计。

敌方有效英雄击杀仍在闪光的持有者时继承积分增益；普通战斗单位补刀同样按目标的单条英雄记录追溯，接收英雄必须与持有者敌对。每传递一次，时长减少15秒；领取后重新计时，与上一位持有者已经消耗多少时间无关。

| 持有顺序（含击杀精英） | 奖励 |
|---|---:|
| 第一位 | 60秒BUFF |
| 第二位 | 45秒BUFF |
| 第三位 | 30秒BUFF |
| 第四位 | 15秒BUFF |
| 第五位 | 一次性200积分，传递结束 |

第五位获得的200积分固定发放，不享受50%增幅，也不再从这条链获得BUFF。若接收者已持有另一条链，则保留其已有增益；正常继承新一棒时替换为该棒的时长与代数，不叠加。

怪物及持有此增益的英雄均有金色脉冲、脚下光环和上浮星光，便于双方识别；英雄显示状态图标和倒计时。精英奖励、继承和末棒积分均向所有在线玩家广播6秒，并加入战报。

倒计时结束停止闪光，不因自然到期发放200分。过期后击杀、友方击杀、已阵亡英雄的延迟击杀不继承；没有有效接收英雄时传递链结束。死亡和战区重建清除持有状态。规则同时适用于经典玩法和当前设计稿。
