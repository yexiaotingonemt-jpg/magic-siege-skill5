## 3. 战场与阶段

### 3.1 战场空间

| 概念 | 定义 |
|---|---|
| 格 | 战场距离单位。单位中心间使用平面直线距离计算。 |
| 纵向 | 进攻方由南向北推进；防守方由北向南推进。 |
| 世界边界 | 全部普通移动、换位和强制位移可到达的位置边界。 |
| 推进边界 | 无目标前进的停止位置。防守方另限制普通追击向南深入。 |
| 防线排 | 一排防御塔。该排全部塔被摧毁后，前线推进至下一排。 |

战场横向范围为X=-10.5～10.5格，纵向范围为Y=-64～76格。进攻方无目标前进的终点为Y=76，防守方为Y=-38。地图边界限制所有移动，角色体积不参与距离扣减。

防御塔共3排，每排6座。相邻塔横向间距3.6格，排间距14格。三排塔的纵坐标分别为0、14、28。横坐标以战场中心对称排列。

### 3.2 阶段胜负与重建

一个阶段持续3600秒。进攻方在时限内突破1排防线时获胜；到达时限仍未达成突破条件时，防守方获胜。胜负在同一模拟步同时满足时，突破条件优先。

阶段结束按以下顺序处理：

1. 记录胜方、阶段编号、结束时间和该阵营累计胜场。
2. 已加入本局的胜方账号各获得100积分，不按个人贡献拆分；在线状态不作为领取条件。
3. 结算尚存活的契约英雄，执行[第12章](12-ratings-and-scores.md)的英雄评价与积分规则。
4. 清除地图单位、塔、弹道、持续场地及表现事件，重建三排防御塔并立即生成新阶段第一波小兵。
5. 所有玩家重新选择单位契约；玩家体力、积分、各职业等级、经验、技能点、构筑及尚未结束的技能冷却保留。
6. 阶段编号加一，按新阶段时长重新计时。

所有防御塔全毁同样触发地图重建，并被判定为进攻方完成突破条件。防线推进以整排塔是否全毁判断，不要求先摧毁某一列。
