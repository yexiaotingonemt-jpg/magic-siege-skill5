# 职业自带被动（0.6.3）

本次只将五职业被动接入正式旧技能；主动技能、等级与词条池、契约费用和KDA公式沿用0.6.2。未切换本地整套新版开发规则。正式战局自动开启被动，真人与NPC使用相同规则。英雄状态区“被动”按钮以及“技能 → 被动”页显示当前战局的真实配置。

- 兽人：每损失10%生命，额外减伤2.5%，连续计算，最高25%；与不同来源减伤乘算，沿用正式技能原有最终减伤下限。
- 火法：每层炙热增加5%攻速、降低2%受疗。炙热的来源、上限6层及词条加成、持续时间沿用现有技能，不额外赠送初始炙热。
- 精灵：有效伤害的50%治疗受击点4格内生命比例最低的友方；有效治疗的50%伤害受疗点4格内最近敌人。派生治疗与派生伤害不再次互转；不计过量治疗，也不凭空产生有效伤害。
- 战车：同次技能以主目标计算效果总池，按1/2/3/4/5/6人以上使用100%/90%/80%/70%/60%/50%合计倍率，再均分。实际命中伤害、减益强度及位移按分担比例结算；主动技能的费用、冷却、基础目标数不变。腐蚀按主目标生命计算每跳总池，不因其他目标生命不同而放大。
- 领主：击杀1名英雄或累计3名非召唤小兵，回复最大生命2%、随机净化自身一个有效负面，并驱散最近有增益敌方的一个增益。小兵进度使用独立计数，不与原有升级词条计数混用；建筑与召唤单位不触发，击杀英雄不消耗小兵进度。

被动参数和配套积分校准倍率位于服务器配置`innate`。纯旧规则模拟可关闭该开关；正式Room默认开启，保留战局热更将新增配置合入旧战局。兼容标记0.6.0、协议3及运行schema2保持；发布号0.6.3强制旧客户端先拉取新版。旧英雄、成长、体力、冷却、阶段、已有积分和待执行闭包保留，后续事件按新规则记账，原有积分不会追溯重算。

积分仍为原公式，伤害与按最大生命折算的小兵击杀使用同一系数，英雄击杀200、助攻100、每点实际体力100保持。新增被动后的系数及基准边界见[0.6.3验收记录](../releases/0.6.3-verification-20261102.md)。清除排行由超级账号二次确认后执行；部署本身不清除排行榜。
