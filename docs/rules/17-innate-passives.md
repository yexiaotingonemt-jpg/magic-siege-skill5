# 五职业固有被动

目标0.7.0，默认新战局直接采用当前设计；旧版独立被动模块不再同时结算。

| 职业 | 自动效果 |
|---|---|
| 兽人战士 | 自身每损失1%生命，受到的伤害降低0.25%，最高降低25%。 |
| 火焰法师 | 初始获得1层炙热。每层使攻击速度提高5%、受到的治疗降低2%，最多10层。保留10秒后减少1层，并重新计时。 |
| 森林精灵 | 造成有效伤害时，为目标附近生命比例最低的友军恢复伤害量50%的生命；主动治疗时，对附近1名敌人造成有效治疗量50%的伤害。 |
| 符文战车 | 技能同时命中的敌人越多，造成的总伤害和总减益效果越弱。 |
| 黑暗领主 | 每击杀1名英雄或累计3名小兵，随机清除自身1个负面状态及敌方1个增益状态，并恢复最大生命2%的生命。 |

契约后自动生效，不消耗体力。被动面板显示当前炙热、缺血减伤与领主击杀进度；被动强化与主动、通用强化共享40次预算。炙热的攻速与临时攻击作为同一复合状态驱散，积分奖励不能驱散。
