# 技能释放公共流程

目标0.7.0，四技能在英雄0级全部可用。具体体力、CD、前摇以[各职业技能](10-classes-and-skills.md)为准；不沿用旧版大招5级解锁或统一0.35秒前摇。

施法先验证存活英雄、目标与射程、眩晕、冲锋／引导、前摇、CD和体力；失败不扣费、不记经验。支援技能使用友方目标解析；自施技能无需敌人。成功施法扣除实际体力，计入同口径积分及经验，并保存攻击力、参数和词条快照；本次施法引起的升级不会倒灌当前快照。

可被打断的前摇和持续引导保留真实打断行为。火法焚魂标记不要求炙热、不扣炙热且不立即造成伤害；天火记录施放时炙热，在释放时消耗对应层数并增伤。延迟、持续及在途效果沿用施放快照。

不使用统一伤害／治疗预算截断。具体人数、持续、分担、距离、护盾与派生限制以当前技能为准。客户端显示与服务端读取同一配置。

NPC英雄的施法决策间隔为全局`botCastInterval`的1.5倍（默认4.5秒）。存在可用技能时，每轮有20%概率犹豫并跳过；未跳过时，一半概率沿用职业评分最高的技能，一半概率从正常施法验证通过的技能中等概率选招。跳过后等待下一轮，不扣体力或进入冷却。随机决策使用战局种子，两种技能规则入口均适用。玩家开启自动施法仍按原间隔和职业评分选招。NPC人数、基础属性、普攻与索敌规则不变。
