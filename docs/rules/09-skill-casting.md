# 技能释放公共流程

0.5.0基础技能自动解锁，升级强化由词条提供。服务器依次验证存活英雄、解锁、手动目标范围、控制/引导/前摇、冷却、体力及合法目标。超距优先显示目标太远，不换成附近目标。

成功施法锁定目标和当前词条参数，扣除体力、增加施法积分与经验，再锁定升级后的攻击数值。前摇内后续选敌不改变这次施法，打断不返还体力或冷却。尚在飞行的弹道保留原目标及来源职业。区域技能在固定落点结算；单体目标消失不擅自扩大范围。

每次施法只有记录账本，不再执行2000%／6000%公共收益截断。直接伤害、持续伤害、治疗、控制分别遵守该技能明示人数、次数、时长和局部上限。具体20技能和90类词条见[当前规则](15-traits-and-elites.md)。
