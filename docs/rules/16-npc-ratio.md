# NPC英雄比例与超级账号设置

适用版本：0.6.2，2026-10-31。

超级账号在游戏区域外的“联机体验工具 → NPC补充设置”中设置同局策略。权限仅根据服务端 `super-accounts.json` 中的账号ID判断；现有及后续新增的超级账号均可使用。房主身份本身没有此权限。后端在每次认证时重新读取名单，客户端每10秒刷新入口，授权与撤销无需重新登录。

## 模式和比例

- 默认按防守:进攻=1:3补充，支持双方各1～99的整数比例，保存时约分。
- “无NPC”从下一波起停止补充。现有NPC继续移动、攻击、施法和正常死亡，不删除或退役它们；死亡后不补回。
- 改比例或重新开启均在下一次出兵时检查，只补充，不删除真人或NPC英雄。

每波普通兵生成后，统计双方场上存活的玩家英雄与NPC英雄；普通兵、防御塔、召唤单位不计数。防守人数按进攻人数和设定比例向下取整，至少维持一组；已有防守更多时不删除，进攻不足则按现有防守补齐。例如默认1:3时，进攻4～5名维持1名防守，进攻6～8名维持2名防守；现有防守2、进攻1时，补成防守2、进攻6。目标2:5而现有防守3、进攻7时，补成3:8。无玩家英雄时，默认也维持防守1、进攻3。

比例模式下，防守NPC按当前存活英雄人数实时获得施法智能补偿。默认1:4时每4秒决策、1:5时每3.5秒决策，犹豫与随机选招概率同步降低；恢复完整1:3比例后回到普通NPC的4.5秒间隔。补偿仅影响防守NPC选招，不改变属性、冷却或技能合法性。公式及概率见[技能释放公共流程](09-skill-casting.md)。

NPC存活总数上限为99名。缺少合法满血兵或名额时只补可补部分，界面显示缺额，下一波继续检查。原有普通兵生成总数保持不变，NPC通过原地契约产生。

## 契约选择

1. 排除受伤兵、英雄、塔、精英、召唤单位及所有真人当前预选的单位。
2. 优先选择正在攻击范围内交战的满血普通兵（正在攻击敌人，或正被敌人攻击）。
3. 前线没有可用满血兵时，选择后方赶路的满血普通兵。
4. 在当前优先级中，从有合法兵源的开放职业中等概率随机选择职业，再选该职业最靠前的满血兵。进攻可出现兽人战士、火焰法师、森林精灵、符文战车；防守为黑暗领主。

契约沿用正常费用、属性、贡献和成长规则。NPC体力不足契约时补回当前初始体力；没有英雄的NPC账号会复用。NPC不会在两波之间自动重新契约，普通玩家的手动契约不受影响。

## 配置生命周期

设置保存在当前服务进程，随重建战场、阶段推进、超级账号重开本局及兼容热更保留。完整进程重启后恢复默认1:3。由旧版保留战局热更至0.6.2时，保留所有英雄、成长、积分、会话与计时，首次在下一次出兵检查默认比例。

`npcPolicy` 命令格式：`{id,type:"npcPolicy",args:{mode:"ratio"或"off",defense:1,attack:3}}`。旧的 `bots` 固定数量命令停用，完整配置中的历史 `attackBots`、`defenseBots`、`botMode` 不参与同局NPC补充逻辑。
