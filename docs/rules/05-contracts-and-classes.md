## 5. 单位契约与职业

### 5.1 职业与兵种映射

| 阵营 | 场上小兵 | 可契约职业 |
|---|---|---|
| 进攻 | 近战 | 兽人战士 |
| 进攻 | 远程 | 火焰法师、森林精灵 |
| 进攻 | 攻城 | 符文战车 |
| 防守 | 近战 | 黑暗领主 |

其余阵营与兵种组合不可契约。玩家只能契约本阵营的存活普通小兵，不可契约塔、英雄或已离场单位。

### 5.2 契约流程

1. 未拥有存活英雄时，点击场上的己方合法普通小兵，进入单位选择状态，显示契约弹窗。
2. 同一位置有重叠小兵时，可在弹窗候选中切换单位；同兵种对应多个职业时，在弹窗内选择职业。
3. 点击“契约”后，重新验证单位、阵营、兵种、玩家英雄占用及体力。
4. 验证通过，扣除3体力，原单位在原位置转化为所选英雄，不额外生成另一单位。
5. 英雄继承该小兵当前生命百分比，按该玩家所选职业的等级计算最大生命和攻击。
6. 清除旧手动目标，采用该职业构筑，沿用该玩家四个技能槽的现有冷却，进入英雄控制状态。换职业不清空槽位冷却，冷却不按职业分别储存。

取消、点击空白或选择本身不扣费。单位死亡、被其他人契约或失效时，选择清除；多个玩家争抢同一单位时，以先通过服务端验证的契约为准。

英雄阵亡后可重新契约；同职业的成长和构筑在同一战局内继承。存在存活英雄时，不能直接换职业或契约另一单位。
