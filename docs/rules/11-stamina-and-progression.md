# 体力、经验与词条构筑

0.5.0取消技能点和技能等级。初始1/2/3技能，大招5级自动解锁；每次英雄升级获得属性成长及一次词条选择。完整数值、次数、候选、经验曲线与保留规则见[升级词条与精英兵](15-traits-and-elites.md)。

契约费用保持3体力，获得300经验；技能按配置扣除体力，每实际消耗1点体力获得100经验，失败操作不扣费、不加经验。0级起步，每级需5～10点体力，累计300点体力升至40级。技能中断不返还已付体力。死亡不刷新CD，不同职业按技能位继承剩余冷却。体力和积分归账号，等级、经验、词条和队列按职业保存；阶段重建保留，服务器重启重置本场成长。

没有自动体力恢复；体验工具可为本人增加100体力。选择词条不刷新冷却、不返还费用，不允许重分或重抽。
