# 体力、经验与成长

目标0.7.0。职业从0级开始，四个技能基础效果全部可用。契约实际消耗3点体力并计分，契约不提供经验。成功施法每消耗1点体力获得1点经验，每3点经验升1级，上限40级；击杀、塔伤和推塔不再提供成长经验。

每级提供1次词条升级，全部主动、职业被动与通用强化共用40次预算；每升1档消耗1次，并遵守职业与最高档限制。各档相对基础，不累计前档，不逐档复利。升级和生命强化保持当前生命比例，职业成长及构筑保留至重开本局。

生命与攻击成长分别读取current-design-data.js的heroes配置。同属性百分比强化相加后作用于该等级基础值；不同来源的技能减伤、对塔减伤和最终减伤相乘。

候选按统一品质权重先抽品质，再在该品质合法未满档词条中抽取；满档品质退出可选池。固定蓝紫金次数库存已停用。概率定稿与平衡状态见[词条及精英](15-traits-and-elites.md)。
