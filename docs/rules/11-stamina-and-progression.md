# 体力、经验与成长

每实际消耗1点体力获得100经验，包含契约和施法；失败操作、补充体力、击杀、塔伤及毁塔不提供经验。0级起步、40级封顶；升级余量保留，每升1级获得1次词条三选一机会，累计40次。契约成功消耗3点体力并获得300经验。每级门槛5～10点体力，升满共需300点，详见[配置表](../数值配置表.md)。

每级提供1次词条升级，全部主动、职业被动与通用强化共用40次预算；每升1档消耗1次，并遵守职业与最高档限制。各档相对基础，不累计前档，不逐档复利。升级和生命强化保持当前生命比例，职业成长及构筑保留至重开本局。

技能强化仅能在本次英雄阵亡后、下次契约前选择。契约期间经验、等级及基础属性正常成长，强化次数累计但不能点击使用；阵亡后可连续消耗多次，也可保留未使用次数。重新契约后再次锁定，须等待本次阵亡。次数和已选强化按职业保存，断线重连不丢失、不自动弹窗。战区重建与机器人退场不视作阵亡，不解锁本次新累计的次数。NPC同样在阵亡后、再次契约前选择强化。

生命与攻击成长分别读取current-design-data.js的heroes配置。同属性百分比强化相加后作用于该等级基础值；不同来源的技能减伤、对塔减伤和最终减伤相乘。

候选按统一品质权重先抽品质，再在该品质合法未满档词条中抽取；满档品质退出可选池。固定蓝紫金次数库存已停用。概率定稿与平衡状态见[词条及精英](15-traits-and-elites.md)。
