# 当前技能实现与配置

本次按2026-11-02读取的钉钉当前六个分页核对五职业20技能、5个被动和104种词条；通用项展开143个职业实例。目标版本0.7.0，GAME_VERSION 0.7.0、战局schema3、账号schema1。正式服部署状态见发布记录，本次为代码提交。

## 默认入口

npm start直接启动当前设计API（默认5183），不再需要额外启动参数。普通新建Room同样采用当前设计；legacyLiveConfig只用于旧规则回归。npm run start:design保留为独立开发预览入口（默认5185与E盘隔离数据），与常规入口采用同一技能配置。客户端本地预览可设置MAGIC_SERVER_URL后运行npm run dev。

当前参数在shared/current-design-data.js。heroes为面板与成长，skills为技能费用、CD、范围和效果，affixes为档值、品质与上限，rules为职业资源、派生与计分常量，scoreCoefficients为钉钉当前系数。档值相对baseline表达增量，各档不累计前档。全部时间、百分比严格采用当前稿，不为满足另一个约束擅自取整或改值。

火球“贯穿火球”词条按钉钉最新确认效果采用`path_damage`：基础为0，金色1档增加1.5，即沿途额外150%攻击伤害。原火球、目标数及击杀获热保留；按各颗原火球的施法位置到目标位置确定路径，多条路径中的同一敌人只追加一次。击退前固定路径，伤害使用施法快照并沿用伤害、击杀、积分与KDA记录。新施法不再生成巨大贯穿火球或周期伤害，旧`currentPierce`处理仅供已经在途的旧效果收尾。

支持--design-config=<绝对JSON路径>读取完整配置或设计对象；已有持续效果保留施放快照。数值编辑器保留标识、描述和布尔开关，只编辑数值。

## 兼容与验证

旧0.6.x的技能、词条ID、成长与计分口径不能在原战局中混用。保留战局热更会明确拒绝不兼容规则；需要另行明确选择新战局或常规部署。账号／会话结构保持，不自动清除正式数据。

npm run test:design、npm test和浏览器当前设计用例校验数据、实际效果、成长、计分和界面。npm run test:balance仍为旧规则诊断入口，固定使用legacyLiveConfig，不能证明新规则平衡通过。

完整核对范围、回归结果、当前稿与平衡约束冲突以及发布限制见[整体核对记录](releases/0.7.0-skill-alignment-20261102.md)。

## 经验升级曲线

每实际消耗1点体力获得100经验，包含契约和施法；失败操作、补充体力、击杀、塔伤及毁塔不提供经验。0级起步、40级封顶；升级余量保留，每升1级获得1次词条三选一机会，累计40次。

| 升至等级 | 每级体力 | 每级经验 | 本段体力 | 累计体力 |
|---|---:|---:|---:|---:|
| 1～7级 | 5 | 500 | 35 | 35 |
| 8～14级 | 6 | 600 | 42 | 77 |
| 15～20级 | 7 | 700 | 42 | 119 |
| 21～26级 | 8 | 800 | 48 | 167 |
| 27～33级 | 9 | 900 | 63 | 230 |
| 34～40级 | 10 | 1000 | 70 | 300 |

合计300点体力、30000经验。`rules.expPerStamina`为每体力经验，`rules.levelUpStamina`为40项整数体力门槛，数组下标0对应升至1级；创建配置时同步到`world`同名字段。

保留战局发布时，旧经验余量按倍率从1换算为100；已有等级、词条、待选队列、体力、积分与冷却保留。换算在激活时执行，失败回滚会恢复旧余量，后续同倍率更新不重复换算。
