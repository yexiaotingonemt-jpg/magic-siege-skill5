# 魔法王座当前数值配置 · 0.5.0

规则和90类词条的完整数值见[升级词条与精英兵](rules/15-traits-and-elites.md)。以下为shared/config.js当前默认值展开，仅记录静态配置，不记录玩家实例数据。具体修改时机沿用开发协作指南。
