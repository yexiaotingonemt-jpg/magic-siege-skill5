# 魔法王座数值配置表

## 1. 数值口径

本表记录与玩法规则配套的静态默认值，不记录玩家当前生命、积分、冷却等实例状态。技能攻击和治疗系数为技能1级，英雄属性为英雄1级；实际成长、触发与分摊见[玩法规则](玩法规则.md)。修改与读取时机见[开发协作指南](开发协作指南.md)。

字段类型`digit`表示单个数值。备注中的当前值为便于阅读的显示值：攻击力系数显示为1200%时，原配置`power`存1200；普通比例显示为35%时，原配置存0.35。倍率直接存倍数。

距离单位为格，时间为秒，普通攻击间隔为秒/次。所有百分比均已反映当前技能强度；不在回填时再次统一翻倍。

职业编号：0=兽人战士、2=符文战车、3=黑暗领主、4=火焰法师、5=森林精灵。技能数组下标0～3对应1～4技能。阵营编号0=进攻、1=防守。

未开放职业、未参与评价的指标、通用结构占位和未被当前行动逻辑读取的字段不作为本组生效参数。完整原始快照仍可保留这些键，更新既有配置时不能仅因未列入本表而删除结构。
