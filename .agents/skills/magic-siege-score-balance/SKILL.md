# 魔法王座技能与积分校准

修改技能、面板、成长、费用、词条、品质概率或积分时使用。用户当次指令优先。

先读 [当前设计契约](references/design-contract.md)，其中40项规则和8阶段流程是当前验收依据；不能套用旧实现的固定8／3／2／1次数或总积分÷实际体力作为新稿KDA。

## 执行顺序

1. 固定参数、模型、场景、等级、构筑与验收口径；用手算和实际引擎小例先校验公式。
2. 校准基础技能、英雄、箭塔与小兵；复验同压总生存及基础战斗。
3. 校准全部既有词条、档位、品质及统一概率，检查40次共享预算、每档可感知、同品质单档收益差≤3倍。先补场景缺口，不能把模型零估值当成效果无效。
4. 验含词条后的同英雄技能常态综合净收益／体力差≤2倍；用实际二维引擎和18座塔验1V3。标准每名玩家每分钟实际施法18点、契约3点，固定5／20／40级、5分钟且不成长；前1分钟形成战线，后4分钟验稳定或往返。先固定混合组合，再查三同职业等边界。不得用单塔投影或单位位置均值替代接触线。
5. 战斗通过后冻结逐事件原始统计，才拟合每职业跨等级／构筑共用的计分系数；计分迭代复用同版本统计。
6. 全部相关门禁通过后，按用户授权更新钉钉；写前对比当前文档，写后回读，旧稿与实验留本地。

## 计分门禁

B＝a(D＋M)＋bT＋cH＋200K＋100A；P＝100S＋B；KDA＝B／max(S,21)。D为有效伤害含盾吸、M为被击杀小兵最大生命之和、T为原始承伤、H为有效治疗、K／A为英雄击杀／助攻。使用现有统计归属，不新增保护或打断积分。纯团队保护作为协作收益。

正常60秒：无词条与合法含词条主组分别验，五职业总分及KDA各自相对同级均值±10%；承伤积分／个人总分＜20%；搜索不施法高收益构筑后，其KDA≤正常参考80%。同英雄、等级、构筑、实际体力和窗口下验好≥正常1.2倍、差≤正常0.8倍、好／差战斗分≥1.5倍、好／差总分≥1.2倍。不因时机标签乘分，不用外部续命冒充自然生存。

## 验证与维护

先廉价预检，失败即停对应下游；局部变动只回归依赖场景，通过后再全量验收。保存参数／模型／场景／构筑与原始统计的指纹，不将估值预检写成真实战斗通过。数值变动仍运行npm run test:balance，并说明旧入口与新稿覆盖差异，不强改旧入口来制造通过。
